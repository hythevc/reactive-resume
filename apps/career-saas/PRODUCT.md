# CareerOS product

Candidates use CareerOS to record an opportunity, choose or tailor a resume, review their application package and track the outcome. CareerOS currently ships as a responsive browser application. The Reactive Resume native client is a separate surface with shared repository infrastructure.

Marketing should help visitors understand the workspace and start a real task. The workspace should make the next action and the current application visible. The optional cloud account handles explicit private resume copies where configured.
